# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project participants are expected to contribute in a professional, respectful and constructive manner.

Instances of abusive, harassing or otherwise unacceptable behavior may be reported privately to the repository owner through the contact information available on the owner's GitHub profile.

Until a dedicated moderation team exists, enforcement decisions are the responsibility of the repository owner and should follow the Contributor Covenant enforcement guidelines.
