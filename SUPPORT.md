# Support

Use GitHub Issues for reproducible bugs, feature requests, methodology discussions, regulatory-profile changes and performance problems.

Before opening an issue, identify the category:

- **Security vulnerability:** follow `SECURITY.md`; do not disclose exploitable details publicly.
- **Bug:** include reproducible input/fixture, expected behavior and actual behavior.
- **Methodology:** explain which construct, variable, protocol rule or metric is affected.
- **Regulatory profile:** cite the authoritative legal/regulatory source and describe the observable evidence being mapped.
- **Performance:** include dataset size, concurrency configuration, runtime environment and measurements.
- **General usage:** provide the command/configuration used and relevant non-sensitive logs.

Privacy Evidence does not provide legal advice or legal-compliance certification.
