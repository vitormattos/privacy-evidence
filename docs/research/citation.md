# Citation and scholarly releases

Privacy Evidence is a software research artifact independent from the historical 2025 monograph.

## Software authorship

For the current project foundation, the software author recorded in `CITATION.cff` is **Vitor Mattos**, consistent with the confirmed project ownership/copyright metadata.

Future contributor credit must be based on actual contributions and should not be inferred automatically from issue participation alone.

## Historical study

The 2025 IPB/TCC study is a separate scholarly artifact. Privacy Evidence may cite it as the origin of the research problem and legacy baseline, but software releases must not imply that the monograph and this repository are the same citable object.

## Version-specific citation

Once releases begin, `CITATION.cff` should include the released software version and release date. Research papers should cite the exact software release or archived DOI used for a ResearchRun whenever reproducibility depends on that version.

## DOI/archive policy

Use Zenodo or an equivalent long-term scholarly archive for milestone research releases once the first release intended for external scholarly reuse is ready. The archived record should contain or reference:
- Git tag/release;
- software version;
- research protocol/profile/schema versions;
- citation metadata;
- license;
- replication-package identifier when applicable.

Do not mint a DOI for every development commit. Archive intentional research releases.
