# Brazil cookie-evidence profile

Profile version: **1.0.0-draft**

## Authoritative source

ANPD, *Guia Orientativo Cookies e Proteção de Dados Pessoais*:
https://www.gov.br/anpd/pt-br/centrais-de-conteudo/materiais-educativos-e-publicacoes/guia_orientativo_cookies_e_protecao_de_dados_pessoais

The ANPD describes the guide as orientative/educational material. Privacy Evidence therefore distinguishes guidance/recommendations from statutory obligations.

## Observable evidence

- cookie notice/banner;
- disclosed purposes/categories;
- third-party disclosure;
- accept/reject/preferences controls;
- browser-observed cookies/storage/network behavior where the experiment calls for it.

## Output

The profile reports evidence against the versioned measurement rules. It does not label the site “LGPD compliant”.
