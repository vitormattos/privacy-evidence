# Project agent Skills

Privacy Evidence keeps project-specific reusable agent workflows here. They complement, but do not replace, `AGENTS.md`, canonical docs, CI or issue acceptance criteria.

Current Skills:

- `validate-detector-change`: validate detector behavior, regression fixtures and evaluation impact.
- `add-regulatory-requirement`: map authoritative regulatory sources to generic observable evidence.
- `prepare-research-pr`: apply engineering, security, reproducibility and methodology checks before merge.

These Skills intentionally encode workflows that are now stable in the repository. New Skills should only be added after the underlying workflow is documented and manually validated.
