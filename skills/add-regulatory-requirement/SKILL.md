# Add regulatory requirements

1. Read `AGENTS.md`, issue #88, the target profile documentation and generic PrivacyEvidence taxonomy.
2. Research current authoritative primary sources; prefer legislation, regulators and official guidance.
3. Record the exact source/provision and applicability conditions.
4. State what is publicly observable and what cannot be verified from a website.
5. Reuse generic evidence types; do not encode jurisdiction article numbers into detector contracts.
6. Add mapping fixtures/tests for present, absent, unknown, not-applicable and ambiguous cases.
7. Missing public evidence must not become an automatic organization-level non-compliance verdict.
8. Update the regulatory-profile version when mapping semantics change.
9. Update canonical docs and cite sources.
10. Finish with the issue completion protocol from AGENTS.md.
